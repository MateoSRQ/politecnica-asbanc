# 📌 Instrucciones para Agentes - Politécnica ASBANC

Este proyecto opera bajo un protocolo de **Memoria Viva Continua**.

## Archivo Central de Memoria
Toda la información de arquitectura, diseño, catálogo de componentes, bitácora (ADR) y logs de cambios se gestiona centralizadamente en:
👉 **[`PROJECT_MEMORY.md`](./PROJECT_MEMORY.md)**

## Reglas Mandatorias para Agentes:
1. **Inicio de sesión**: Leer obligatoriamente [`PROJECT_MEMORY.md`](./PROJECT_MEMORY.md) para comprender el contexto actual, la arquitectura y las tareas pendientes.
2. **Con cada cambio**: Actualizar [`PROJECT_MEMORY.md`](./PROJECT_MEMORY.md) en su respectiva sección (Bitácora, Log de Cambios, Componentes, Arquitectura o Roadmap) inmediatamente tras aplicar modificaciones en el código o configuración.
